## Narrow changes here

1. The authenticated gateway labels 409/503 generated by the Engine with X-Montara-Stage-Origin: engine, and its own internal 409/503 with X-Montara-Stage-Origin: owner-gateway. An absent header is ambiguous (edge or uninstrumented code), never a conclusive Cloudflare verdict.
2. Server-Timing contains only millisecond numbers for owner, broker and Engine where measurable. It includes no owner IDs, tokens, project paths or filenames. This is backend time, not browser/Cloudflare latency.
3. Browser hover preview does not convert an HTTP 202 pending JSON into an MP4 blob after 150 polls. A status-200 JSON/HTML response is also rejected as a video. The authenticated 202 to 200 MP4 flow and cancellation behavior are preserved.
4. No auto-replay of a failed Save or 503, and no implicit reset of edit state.
